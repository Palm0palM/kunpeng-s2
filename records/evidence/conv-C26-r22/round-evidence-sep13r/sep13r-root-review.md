# R 主流程、登记和比较独立审查

根代理完整阅读 R record-group、submit main 与 compare，并核对共享 experiment.comparison 的实际规则。门禁函数另由独立代理审查，不在此重复宣称其结论。

固定 C26-r22/C51/C40-r4/C26-r23，每成员三套原 benchmark、共 48 个样本。先要求真实 Q 已通过并冻结；保存 campaign 预约后才建立三个新 control/reference 快照，已有 campaign 或成员 ID 拒绝重提。源码/runner/benchmark 与实际 N/C6 设置关联，共享锁内再次核对源和历史记录；仅在显式 --go 后执行 SSH 或建立实验。

登记只使用同一已保存 job。真实 scheduler、job/system、wrapper、四用例×三样本、完整机器配置全部校验；已记录通过的成员保留，失败成员不覆盖。沿用 N 的最小元数据适配：准备记录、当前源和上传清单一致后使用内存元数据视图，不强迫创建文件的父源码身份被修改。

比较收齐四份记录后再次确认同机同组，保留所有 48 个样本与逐例波动。C51 必须对前后 C6 都超过 max(1%, 比较双方全部逐例波动)，且任一用例退步不超过 1%；阈值使用共享实际规则，没有筛掉慢样本。C40-r4 只作参考，资格始终 false；C51/C40 辅助比较不替代 C6 门槛。通过只列入 confirmation_pending，不自动复测、晋级或打包。

静态未发现主流程/登记/比较阻碍。本审查没有执行 R 工具或本机算子；最终门禁独立审查结束后，由根代理决定一次 R 提交。
