# C28-row4x6u1：四行 × 六向量，卷积核列单步推进

- 来源父候选：C24-row4x4；创建时 experiment parent 为 C24-row4x4。后续性能测量若采用新控制记录，根代理另保留 source_parent 并在测量前登记比较父记录。
- 状态：代码 prepared；C28 尚未编译、运行正确性检查或测量性能。所有验证只在超算调度分配的计算节点执行。
- 单一假设：用更宽的四行输出块配合 kernel 列单步累加，去掉两列窗口 shuffle，并降低每单位输出的系数广播；用更多输入加载、内层循环分支和累加器换取这种收益。

## 实现范围

仅改 `source/conv2d.c` 的 `conv_sve_rowquad` 函数体：每行 6 个 SVE 向量，四行共 24 个独立累加器；七个输入行阶段均采用 `for (int ik = 0; ik < kw; ++ik)`。每个输入向量在源代码的独立块作用域内加载，立即用于当前阶段活跃的输出行，然后结束作用域，不显式同时持有多个输入向量。不加入 asm 或新的编译参数；作用域不保证 GCC 最终调度。

保留 helper 名称、kh<4 回退、尾列三行+单行回退、外层四行分组/OMP 调度、剩余输出行处理、其它 SVE helpers、非 SVE 路径以及 benchmark/runner/源码 README。没有修改已测 C24 或主目录算子。

## 七阶段与严格浮点顺序

| 输入行 t | 活跃输出行及其 kernel 行 |
| --- | --- |
| 0 | a:0 |
| 1 | a:1，b:0 |
| 2 | a:2，b:1，c:0 |
| 3..kh-1 | a:t，b:t-1，c:t-2，d:t-3 |
| kh | b:kh-1，c:kh-2，d:kh-3 |
| kh+1 | c:kh-1，d:kh-2 |
| kh+2 | d:kh-1 |

kh>=4 时各输出都恰好按 kernel 行 0..kh-1 顺序访问，且每一行内 ik 严格从 0 到 kw-1。每次仍为独立 `svmul_f32_x` 后 `svadd_f32_x`；不分拆同一输出的部分和、不重排、不使用 FMA。保持原 `-fno-fast-math -ffp-contract=off`。kh<4 完全沿用原回退。

## 归一化取舍，不预填提速

只比较四行都活跃的主循环，忽略奇列收尾和输入行边界阶段：

| 每次内层循环 | C24：4VL×4行，双列 | C28：6VL×4行，单列 |
| --- | ---: | ---: |
| 输出向量×kernel列工作量 | 32 | 24 |
| fmul / fadd | 32 / 32 | 24 / 24 |
| 输入向量加载 | 5 | 6 |
| 系数广播 | 8 | 4 |
| ext / movprfx | C24 实汇编各 3 | 无显式窗口 shuffle |
| 内层回边 | 1 | 1 |

因此相对 C24，每单位输出×系数的输入加载约增加 **60%**、系数广播减少 **33.3%**、内层回边增加 **33.3%**；横向输出块数量约减少 **33.3%**。不能宣称内层 branch 摊销改善。相对 C26 的直接窗口加载，归一化输入加载率相同。上述为源码/已有 C24 汇编层面的主循环数量分析，不是 C28 指令或性能实测。

理想流式调度预算为 24 个 accumulator + 4 个系数 + 1 个输入 + 1 个乘积 ≈ **30 个 z 寄存器**。这只是可能的调度，不是寄存器分配保证；GCC 若保留多个输入、提前生成多个乘积或跨阶段延长活跃范围，仍可能 spill。更宽尾块、更多加载和内层循环指令也可能导致退化。

## 静态边界审查

- quad 的 kh>=4 条件保持不变；七阶段 kernel 行表达式都在 0..kh-1 内，且 `kh+1/kh+2` 在加法之前转为 size_t。
- block=6*svcntw()；完整块条件仍为 `ow-i>=block`。因此当前块最大输入列为 `i+(kw-1)+6*lanes-1`，不超过 `ow+kw-2=inputWidth-1`。每个向量直接读取有效完整窗口，无额外 v6 或右侧预读。
- 当前输出四行有效时 `j+3<=oh-1`，最大输入行 `j+kh+2<=inputHeight-1`；输入行位移仍使用 size_t，延续父实现的地址范围前提。
- 输出最大列 `i+6*lanes-1<=ow-1`；每个完整块写四行各六向量。循环进入时 `i<=ow-block`，故 `i+=block<=ow`，不新增 int 溢出。
- 余下不足 6VL 的列完全交给原 triple/prefix 回退；剩余1..3输出行的原外层调度没有改变。
