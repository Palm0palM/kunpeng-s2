# TRSM r9：宽核确认与前代调度约束

r8 作业 1579444 已完整登记发布，T11 大用例稳定快 3.57%，但整体收益 0.38% 未超过 11.52% 波动门槛，未晋级。本轮不删除旧结果、不从旧样本中挑选时间，使用全新同分配运行确认。

三个成员依次为 A=T8-control12-repeat-r9、B=T11-sve8x16-repeat-r9、C=T12-forwardbarrier。A/B 是各自同源码版本的新增 run，保留原版本和 prior-record 链；C 从仍为最佳的 T8 派生，只在小核块内前代 q=3/7/11 后约束 a15 的编译调度。T11 与 T12 是独立改动，不叠加成新实现。

在本轮任何新性能数据前固定协议：先分别通过通用预检，T11 再做既有宽核预检；随后 A/B/C 各执行一套完整原官方 warm-up，再按 ABC/BCA/CAB 各跑三套正式官方用例，每套 TEST_RUNS=3。预热单独留证，正式三套全部计入比较，不删除慢样本。总计预期 27 个正式结果与 9 个预热结果；每个候选只与同一作业内的 T8 比较。

固定 38 CPU、单 NUMA、24GiB、1800 秒，真实 KML25.1/GCC12，generic target、原精度、线程绑定和 benchmark 不变。所有编译、预检、汇编及性能运行仅在调度计算节点执行。无哈希、不本机测试、不用重置卡、不关机、不取消他人作业、不提交比赛。

prepare 冻结独立 payload 后 submit 只调用一次并立即保存 job ID，后续按该 ID 恢复。r8 的 payload、记录快照和原始日志均保留。完整取回后先登记两份复测（完整 prior-record 留存），再登记 T12 并比较；只有通过稳定提升门槛后才晋级并独立验证新 ZIP。
