# C51 独立源码审查

根代理直接阅读完整七行 helper、十三个阶段、全部 store 和尾列/防御回退，以及七行分派和剩余一至六行分支；同时阅读一次性源生成器，逐段比较 C40 冻结来源的实际源文件。变化只在新 helper 及最先选择的组分派。原 helper、输入检查、后续 SVE/非 SVE 分派和另外三个提交文件保持原字节。

每个输出 r 在输入行 t 使用 kernel[t-r]：开头 t=0..5 只更新 r<=t；共享 t=6..kh-1 更新七行；结尾 t=kh+q、q=0..5 只更新 r>q。对每个输出，kernel 行从 0 到 kh-1 恰好按序出现一次，内部 ik 保持从 0 到 kw-1。三个向量的 21 个累加器各自执行独立乘法与加法，没有分拆归约、重关联、FMA intrinsic 或 asm。

完整块满足 ow-i>=3VL，因此最大列读取 i+3VL-1+kw-1 不超过 inputWidth-1。七行块最后读取相对输入行 kh+5，正是第七输出所需的最后一行。kh<7 防御分支及横向尾部使用 quad+triple，保留全局 stride；七行分派只构造存在行的指针，余六行 quad+pair、余五行 quad+prefix、其余旧 helper。组数用 size_t 除法与余数计算，未引入 oh+6 溢出。

源码层面未发现阻碍，可准备独立的超算诊断。21 个累加器不证明真实零 spill；必须检查 GCC10 实际产物。尚无 C51 编译、数值或性能结果，C40/C48 的通过不可代替 C51。此审查只做轻量文本读取和比较，没有执行本机算子或使用重置卡；诊断工作流仍须另行审查。
