## 七个输入行阶段

仅 kh >= 4 时执行 quad 主块，每输出行四个向量，十六个累加器贯穿整个 kernel。

| 输入行 t | 参与输出与 kernel 行 |
| --- | --- |
| 0 | a:0 |
| 1 | a:1，b:0 |
| 2 | a:2，b:1，c:0 |
| 3..kh-1 | a:t，b:t-1，c:t-2，d:t-3 |
| kh | b:kh-1，c:kh-2，d:kh-3 |
| kh+1 | c:kh-1，d:kh-2 |
| kh+2 | d:kh-1 |

每个输出收到的 kernel 行恰为 0..kh-1。每行内部沿原 ik 顺序，两系数循环对每个累加器先加独立 k0 乘积、再加独立 k1 乘积；单个奇数尾系数最后处理。没有 FMA、横向归约或重组同一输出的 partial sum。热点不使用逐累加器条件分支。

每次双系数四向量块加载 v0..v3，前三个偏移窗口用相邻 svext 构造，最后从 p+3*lanes+1 单独加载安全窗口。共享的输入同时供当前阶段所有有效输出使用；中段需要八个系数广播，因此不能只按输入加载减少推断性能。

## 回退与入口

- kh<4：quad 入口立即调用原 conv_sve_rowtriple 处理前三输出行，再用 conv_sve_prefix 处理第四行；kh=1/2 的 triple 继续沿原 pair+prefix 回退。
- 主块后剩余列：原 triple 处理前三行的剩余列，prefix 处理第四行；不足四向量时全部通过这些原 helpers。
- 外层剩余三行调用 triple，两行调用 pair，一行调用 prefix。
- 真正 quad 主块需要 SVE、oh>=4、kh>=4、ow>=4*当前线程 svcntw()；没有按官方输入尺寸特判。

## 静态边界与整数范围

组数使用 oh/4+(oh%4!=0)，不计算 oh+3；合法 group 的 j=group*4 始终 <oh，乘法在 int 范围内。用 oh-j 判断剩余行，不计算可能溢出的 j+3。第三/第四输出地址先以 size_t 计算 2*ow 与 3*ow。

完整四行组满足 j<=oh-4，最大输入行 j+kh+2<=oh+kh-2=inputHeight-1。kh+1/kh+2 先转 size_t 再加，避免 int 中间溢出。t>=3 时 t-1/t-2/t-3 非负；所有 kernel 行都在 0..kh-1，首尾阶段只在 kh>=4 后执行。

主块条件 ow-i>=block 保证 i+block<=ow。双系数循环 ik<=kw-2，最后偏移窗口的最大输入列是 i+ik+block<=ow+kw-2=inputWidth-1；不会额外完整加载 v4。奇数尾系数最大输入列 i+ik+block-1<=inputWidth-1，store 的最大输出列 i+block-1<ow。

每个 OpenMP 任务仅写自己独立的四行组或最后1..3行；输入和kernel只读。SVE 向量长度由执行线程获取。容量与指针有效性仍遵循原接口前提。
