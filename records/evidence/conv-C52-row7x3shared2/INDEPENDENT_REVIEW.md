# C52 shared 两列展开：独立源码审查

根代理阅读完整父子补丁与一次性源生成器。变化仅为 rowseven 的共享阶段内部列循环：每轮依次展开 ik 与 ik+1 的七组系数、三次输入加载、21 次独立乘法和加法；两列各有词法作用域。其后保留原一列循环体处理最多一个剩余列。其余十二阶段、helper 尾部与防御分支、全部分派和另外三个提交文件不变。

kw-ik>=2 保证 ik<=kw-2，因此 ik+1 和 ik+=2 都不超过合法列界。偶数宽度只走完整两列，奇数宽度最后一次原一列更新；kw=1 不进入展开循环。对任一累加器，所有 kernel 行和每行列的顺序保持原样，列 ik 的乘法/加法先于 ik+1；没有部分和、FMA、asm、预取或算术重关联。

两列使用相同原地址公式，只将列索引显式命名为 column。原三向量整块边界仍保证最大读取不越过输入最后一列；另一列只有在存在时执行。生成器逐字保留共享循环外的前后源片段，并从实际冻结 Q 源建立候选。最终纯空白整理只修正两个作用域结束括号的缩进，作者已同步生成器、patch 和 checkpoint；未涉及算术。

静态没有发现算术或边界阻碍。词法作用域不保证 GCC 实际缩短寄存器存活；两列展开可能增加 spill 和代码体积，当前没有 C52 编译、数值或性能证据。未来自己的诊断必须覆盖 kw1/2/3、更多奇偶宽度，并按实际汇编分别审查 shared 两列循环与一列余数；不得将 Q/C51 的 PASS 当作 C52 的结果。此审查未运行本机或超算算子，未授权提交新作业。
