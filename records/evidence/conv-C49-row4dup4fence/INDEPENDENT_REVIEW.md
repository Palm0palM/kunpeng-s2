# C49 源码独立审查

根代理直接审查冻结 C45 与 C49 的完整差异：仅四个 packed 系数的 const 删除，以及 q0、q1、q2 完成后各一段空 volatile asm。每段列出四个 +w 读写 packed 操作数、十六个 w 累加器输入和 memory clobber。其余地址、索引、mul/add 表达式、循环、2/1 列余数与分派在该差异中均未改变。

空模板没有实际写寄存器或内存的指令；packed 读写约束将输入位模式保留到输出，未来 DUP 依赖新编译器定义。累加器输入要求当前列更新可用。没有多指令模板的提前改写风险，因而这里没有需要 early-clobber 的实际写操作。该判断只涉及源码合同，不代替 GCC10.3.1 对 SVE 约束的实际接受。memory 是编译器约束，不是硬件屏障。

无源级算术或边界变更阻碍。目标诊断必须检查实际全部三段约束、七个算法阶段及共享4列/余2列/余1列，逐位结果及各 VL/线程配置；继续记录真实搬移和 spill。若机器安排没有有效变化，不能将其作为新性能方案。尚无 C49 动态正确性或速度结论。

本次只有本地轻量源文本审查和文档写入，没有编译或测试算子。
