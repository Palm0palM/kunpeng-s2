# C25-row3x6：三输出行每行扩为六向量

- 比较父记录：已验证的新 C5 控制 C21-r3；来源实现为 C5（C21-row3x4 / C21-r2）。
- 单一假设：保持三行共享输入设计，仅把每行四个 SVE 向量扩为六个，共十八累加器，以更宽输出覆盖摊薄 kernel 行遍历、广播和循环控制开销。
- 仅修改本候选 conv_sve_rowtriple，保留 helper 名称。五阶段分别更新 a、a/b、a/b/c、b/c、c；每阶段横向双系数与奇数末系数均完整扩至六向量，最终三行各存回 a0..a5、b0..b5、c0..c5。
- 每个输入行、每对横向系数为七次输入向量加载、五次拼接。最后的 k1 窗口从 `p + 5 * lanes + 1` 直接加载，不读取完整 v6；共享中段这组输入供三行十八累加器使用。
- 原 C5 三行组 OpenMP 调度、kh<3 回退、剩余一/两行处理、rowpair、prefix、tail、非 SVE 路径均不变。其他三个 source 文件（README、官方 benchmark、runner）不变。
- 主要风险为十八累加器加六个 kernel 广播造成更高寄存器压力，可能引入向量或地址栈溢出；更宽主块也改变尾部比例。不能由减少循环次数推断提速，须核对计算节点汇编和受控计时。

## 静态数值与范围审查

- 每输出仍恰好按 kernel 行 0..kh−1 升序累加，横向按 k0 后 k1；奇数最后一个系数补算，kw=1 只走单系数循环。乘法与加法分离，不启用 FMA/fast-math，不重组部分和或改变容差。
- kh>=3 时五阶段输入行是 0、1、2..kh−1、kh、kh+1。a/b/c 各自接收到的 kernel 行均为 0..kh−1；此次只增加独立输出向量，不改变任何阶段的行索引。
- 主块条件 `ow - i >= 6 * lanes` 确保 `i + 6 * lanes <= ow`，最大输出下标 `i + 6 * lanes - 1 < ow`。
- 双系数循环 ik<=kw−2；最后偏移 1 加载最大输入列 `i + ik + 6 * lanes <= ow + kw - 2 == inputWidth - 1`。单系数末项最大列 `i + (kw-1) + 6 * lanes - 1 <= inputWidth - 1`。
- 完整三行组满足 j<=oh−3，最大输入行 `j + kh + 1 <= inputHeight - 1`；原代码已将 kh 扩为 size_t 后再加一，未引入 int 加法溢出。组计数与各线程独占三行输出的分配保持原样。
- kh=1/2 仍用原 rowpair 加 prefix；末尾一/两输出行仍用原 prefix/rowpair。宽度余数不足六向量时，逐行原 prefix 调用原四/二向量与掩码 tail，完整覆盖四至六向量之间的余数。
- VL 在当前工作线程内查询，不固定为512位，不根据官方尺寸分支。
