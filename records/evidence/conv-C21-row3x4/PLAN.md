## 核心阶段与数值顺序

对三行完整输出组，kh >= 3 时分五段处理输入行：

| 输入行 t | 有效输出与 kernel 行 |
| --- | --- |
| 0 | a:0 |
| 1 | a:1，b:0 |
| 2..kh-1 | a:t，b:t-1，c:t-2 |
| kh | b:kh-1，c:kh-2 |
| kh+1 | c:kh-1 |

因此 a/b/c 各自收到的 kernel 行恰为 0..kh-1，顺序不变。在每一 kernel 行内部保持原来的双系数循环，每个累加器依次加 k0、k1 的独立 float 乘积；奇数尾系数单独处理。不同输出之间可交错，但没有同输出 partial sum 重组或 FMA。热点不含逐累加器的条件判断。

每对 kernel 列在共享阶段只加载四个原向量和最后一个偏移 1 的向量；前三个移位窗口用相邻拼接获得。当前/后续输入向量按使用顺序声明。实际寄存器调度仍由编译器决定，不承诺无 spill。

kh=1/2 显式调用原 C4 rowpair 处理前两行、prefix 处理第三行。宽度不足四向量或剩余宽度由三次原 prefix 处理。最后不足三输出行时，两行调用原 rowpair，一行调用原 prefix。

## 静态范围证明

- 组数使用 `oh / 3 + (oh % 3 != 0)`，不计算可能溢出的 oh+2。合法 group 的 j=group*3 始终满足 0 <= j < oh，乘法不超 int；用 oh-j 判断剩余行数，不计算 j+2。第三输出指针先把 2 转 size_t 再乘 ow。
- 完整三行组有 j <= oh-3；最大输入行是 j+kh+1 <= oh+kh-2 = inputHeight-1。表达式 kh+1 在 size_t 中计算。输入/kernel/output 存储容量仍遵循原接口前提。
- 中间 t 从 2 到 kh-1；t、t-1、t-2 都是合法 kernel 行。首尾单独阶段在 kh>=3 后执行，kh-2 非负。
- 主块条件 ow-i >= block 保证 i+block<=ow。双系数循环 ik<=kw-2，最后偏移加载的最大列 i+ik+block <= ow+kw-2=inputWidth-1；没有额外完整 v4 加载。
- 单系数循环最大列 i+ik+block-1 <= inputWidth-1；store 最大列 i+block-1<ow。
- SVE lanes 从执行线程读取，不固定硬件向量长度。每个静态任务只写自己三行或末尾一/两行，不发生跨组覆盖。

静态说明不是编译或正确性通过证明。
