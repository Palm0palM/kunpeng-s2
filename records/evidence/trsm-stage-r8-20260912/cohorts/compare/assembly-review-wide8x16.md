# T11 8×16 更新核实际目标汇编审查

2026-09-12。只读分析 r8 作业 1579444 的 `assembly-review-inputs/trsm-wide8x16.s`，对照 r7 的 `../optimization-20260912-r7-compare/diagnostics/preflight-results/T8-control12-repeat-r7/trsm-panel16.s` 中 `update16x8_sve`。行号为相应 `.s` 文件的一基行号。未额外编译、运行测试、SSH、计算哈希或复核源码身份。

**系数复用假设在生成代码中实现：8 个 L 系数各供左右两个 8 列向量使用，且没有热 spill 或核内调用。** 代价是同样 128 个输出需要两次 X 向量加载，回写地址计算也更复杂；不能直接从循环指令减少推断整算子提速。

## 按每次调用的 128 个输出比较

T8 为 16 行×8 列，T11 为 8 行×16 列，每次调用均更新 128 个 double。T8 热循环 `.L14` 在 223 行，主体 224–275；T11 `.L20` 在 427 行，主体 428–466。

|每 k 的实际指令/数据项|T8 16×8|T11 8×16|
|---|---:|---:|
|L 系数内存加载数|16|8|
|`ld1rd` 加载并广播|16|1|
|标量 `ldr d`|0|7|
|`mov z.d,d` 广播|0|7|
|`ld1d` X 向量加载|1|2|
|`fmla`|16|16|
|地址 `add`|17|3|
|循环内 `ptrue`|0|1|
|`cmp` / `bne`|1 / 1|1 / 1|
|热循环总指令|52|39|
|热栈访问 / 核内调用|0 / 0|0 / 0|

这里不能把“8 个广播系数”写成“8 条广播加载指令”。T11 431 行是一次 `ld1rd`；428、430、432、434、436、438、440 行分别是七次标量 `ldr d`，437、439、442–446 行再用七次 `mov z.d,d` 广播。合计 15 条系数加载/广播指令，另有 429 行的 `ptrue p1.b,all`。系数访问使用带行偏移寄存器的加载寻址，避免 T8 每行另做地址 add；T11 三次 add 只推进 L 列指针（441 行）与两个 X 指针（447–448 行）。

449–464 行的 FMA 成对消费同一个系数：例如 z9 分别乘 X0=z1、X1=z0，累加到 z8/z31；其余七行同理。没有重复加载同一行系数来更新第二个半面板。

## 16×16 区块双方都调用两次

T11 的 packed 路径在 `.L162` 的 2390、2403 行调用两次 8×16 核，覆盖上下两个 8 行半块；fallback 在 2429、2441 行同样调用两次。T8 用两次 16×8 核覆盖左右两个 8 列半块。不能将 T11 一次调用与 T8 两次调用比较。

对完整 16×16、每个 k：

- FMA 都是 32 条；调用次数都是每个区块两次，每次调用覆盖整个 count 循环。
- T11 读取 16 个 L double、4 个 X 向量；T8 读取 32 个 L double、2 个 X 向量。有效 VL=8 double 时，架构层面的输入加载有效载荷分别为 `128+256=384` 与 `256+128=384` 字节。复用改善发生在 L，X 在上下半块间的读取增加；不能称总输入字节量减半。
- 两次热循环的静态指令合计分别为 78 与 104 条/每 k。该数字不包括调用点、设置、回写、尾部和共享打包，也不表示周期数或物理内存总线流量。

## 算术、回写与栈

T11 在 401、411–425 行将 16 条累加链设为零。每轮 L 指针增加一个 double，两个 X 指针增加 `ldx*sizeof(double)`，循环至 count 项耗尽；每个 lane 使用递增 k 的单条 FMA 链。历史循环未把 C 装入累加器，没有改成逐项 C-=a*x。

循环后 `.L19`（467 行）才加载 C，做一次 C-sum，再写回。469–545 行按每行左 8 列、右 8 列推进；合计 16 次 C `ld1d`、16 次 `fsub`、16 次 `st1d`，没有额外 FMA 或除法。T8 的 `.L13`（291 行）同样在点积结束后做 16 组 C 读/减/写，跨输出元素的写回遍历顺序不同，但没有改变每个输出自身的累计次序。

回写区间的实际指令数为 T11 78 条（468–545）对 T8 65 条（292–356）。新增开销主要是左右列地址组织：T11 有 17 add、5 smaddl、6 mov，T8 只有 15 add；两者都另有 ptrue 和 sbfiz。这是热循环之外必须计入的成本。

T11 仅在 392 行以 16 字节栈帧保存 d8/d9，546 行恢复；热循环及回写中没有计算临时值落栈。T8 的 96 字节栈帧用于保存 x29/x30 和多组通用寄存器，热循环也无 spill。两核整个函数内都没有 `bl`/`blr`；外层调用点仍有参数准备和活跃值保存，不能把微核叶函数等同为零调用开销。

## 判断范围

生成代码证实每个 L 系数在两个 RHS 半面板间复用，并减少独立地址 add，未以热 spill 抵消。它同时增加 X 加载和回写地址组织，并未降低等输出情况下的架构输入总字节数。

本文不测量缓存命中、吞吐、分支、调用点开销或完整 CT/KB 循环时间，也不替代宽预检和官方正确性日志。r8 正式测量、噪声及是否晋级应以实际登记比较为准，不能由 52→39 条循环指令单独作结论。
