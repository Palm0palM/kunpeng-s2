# C15-pipe8：八累加器双系数输入流式处理

- 父测量：C13-r3；源码起点为当前 C3（C13-exttail）。
- 单一假设：把八个输入向量全加载、全处理 k0 后再全处理 k1 的语句顺序，改为依次完成一个输出向量的 k0/k1，再载入下一相邻输入。期望缩短输入向量生存期，让编译器在 `svext` 时更容易复用已死寄存器，减少复制或寄存器压力。
- 实际改动仅在八向量 SVE 主块的双系数循环；块宽 `8 * svcntw()`、八个累加器、每行线程划分、单系数循环、SVE 尾部、通用回退和运行器不变。
- 每个输出向量仍严格依次执行 `round(acc + round(v * k0))`、`round(acc + round(ext * k1))`。只改变独立输出向量之间的执行顺序；`jk`/`ik` 遍历次序不变，乘法与加法保持分离。
- `v0` 与 `v1` 处理 a0；之后先加载 v2，再处理 a1，依次到 a6。a7 的第二个输入沿用 `p + 7 * lanes + 1` 的完整安全加载，不加载可能越过有效输入列的 v8。
- 两步循环条件仍为 `ik < kw - 1`。主块条件保证 `i + 8 * lanes <= ow`；最后一次偏移 1 加载的末列是 `i + ik + 8 * lanes`，不超过 `ow - 1 + kw - 1 == inputWidth - 1`。
- 风险：编译器可能重新调度回原形，或者相邻 k0/k1 加法依赖降低可隐藏的延迟；仅凭源码安排不能判定汇编或速度改善。
- 待超算计算节点验证：严格官方编译设置、保护页与独立标量参考、多种 SVE 向量长度、SVE 路径命中；随后与 C13-r3 在同资源分配内交错测量，每个版本三轮完整官方套件，检查全部 PASS、误差、逐项中位数与波动。检查热循环汇编是否实际减少复制且未引入栈溢出。
