# C37-row4u1：共享中段每次推进一个系数

来源 C26-row4loads（正式 C6）。单一假设是在保持四行×四向量块形状时，取消共享中段的 kw 两步展开，降低同时活跃的权重、输入和临时乘积数量。循环控制开销会增加；目标调度与性能均未知。

只删除 `conv_sve_rowquad` 的 `t=3..kh-1` 中双列循环，使原单列余数循环从 ik=0 遍历全部 kw。该现有循环每步四个权重广播、四个输入向量及十六对独立乘法/加法，源码未新增数据访问。原六个首尾阶段、所有其它 helper、OMP 分派、回退、benchmark、runner、线程数与编译选项保持不变。

C12-sveu1 曾在旧的单输出行八向量实现上退化；C28-row4x6u1 同时采用六向量形状。两者均不是本轮四行四向量、仅共享中段去展开的同环境证据。这里只将它们作为历史风险，不据此填写 C37 成绩。

每个输出的 kernel 行 t-r、列 ik 仍严格递增，累加器未拆分，保留先乘再加与关闭 FMA。对 kw=1 本来即走相同单列体；奇偶 kw 均逐列完成。kh<4 回退未改，t 最大 kh-1；满块满足 i+4*lanes<=ow，最后输入列 i+ik+4*lanes-1 <= ow+kw-2。没有新指针表达式、输出写入或线程分工。

当前仅 prepared，正确性、目标汇编及性能待超算调度节点验证。预期沿用 C26 的 108888 项多 VL/线程、保护页与分派检查，并检查汇编是否减少 live state/是否 spill/是否仍无 FMA；正确性通过后与未改 C6 同组测量。没有提速则保留 C6 和失败记录，不生成提交包。
