# C18-tailpair：仅四/二向量尾块复用相邻输入

- 父记录为 C13-r3，源码基线为当前 C3（C13-exttail）。
- 单一假设：C3 主八向量块已通过双系数相邻输入拼接减少加载；把同样思路限定应用于原来单系数的四向量、二向量尾块，尝试减少尾部加载与循环控制开销。
- 只改 conv_sve_tail 的四/二向量满块循环。四向量每对系数使用五次输入加载、三次拼接；二向量每对系数使用三次输入加载、一次拼接。块形状、调用入口与尾部拆分方式不变。
- 双系数循环满足 `ik < kw - 1`。每个累加器都先计算 k0 的分离乘法/加法，再计算 k1，跨 jk/ik 顺序严格与参考相同；奇数最后一个系数保留原单系数处理方式。kw=1 只走单系数循环。
- 最后向量的 k1 输入直接加载 `p + (B - 1) * lanes + 1`，B 为 4 或 2，不额外加载完整下一向量。其最大输入列是 `prefix + i + ik + B * lanes`；由 `prefix + i + B * lanes <= overall_ow` 且 `ik <= kw - 2` 可得不超过 `inputWidth - 1`。输出最后列严格小于 overall_ow。
- 原主八向量 conv_sve_prefix 完全不变；最后单向量掩码路径、通用回退、官方 runner/benchmark、线程限制、浮点容差与编译约束均不变。
- 使用当前工作线程的 svcntw()，不固定向量长度、不识别官方尺寸。
- 风险：四/二向量的独立累加依赖较少，双系数展开和拼接可能增加依赖延迟；部分输入的尾部占比很低，收益可能被测量波动覆盖。不能仅凭加载次数判定提速。
