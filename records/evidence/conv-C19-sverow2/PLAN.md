# C19-sverow2：相邻输出行共享输入行

- 父测量 C13-r5；源码基线为 C3（C13-exttail）。
- 假设：将每行八向量主块改为两输出行各四向量，共八累加器。相邻输出行除两端外引用相同输入行，以错开一行的 kernel 索引共享输入加载，减少输入指令及拼接。
- 新增 `conv_sve_rowpair`，宽度 `4 * svcntw()`。顶端输入行只更新第一输出行、kernel 行 0；中段 t=1..kh−1，同一输入行分别更新第一输出行 kernel[t] 和第二输出行 kernel[t−1]；底端 t=kh 只更新第二输出行 kernel[kh−1]。
- 每个中段输入行、每对横向系数使用五次输入向量加载和三次拼接，服务两行共八个累加器；四个系数广播与两行各自的乘法/加法保持独立。首尾输入行使用独立循环，无中段条件分支。
- SVE 路径以输出行对进行 OpenMP 静态分配。`pairs = oh / 2 + oh % 2` 避免计算 oh+1；j=2×pair 仍在输出行范围。奇数最后输出行调用原 C3 prefix。无 SVE 时原通用路径完整保留。
- 每行余下不足四向量的输出分别调用原 `conv_sve_prefix`，使用其既有尾部。C3 prefix、tail、通用块函数均原样保留。

## 严格累加顺序与范围

- 第一输出行的 kernel 行序列为顶端 0、中段 1..kh−1；第二输出行序列为中段 0..kh−2、底端 kh−1。每个输出自身的 kernel 行与列始终升序，不分割 partial sum，不重排加法括号，不引入 FMA。
- kh=1 时中段循环为空，两行分别使用自己的唯一输入行，仍各计算 kernel 行 0。kh 的其他奇偶值不改变顺序。
- 每个横向系数对满足 ik<=kw−2，按 k0 后 k1 的显式分离乘法/加法更新；kw=1 只执行单系数循环，奇数最后系数补算，偶数完整按对计算。
- 成对 helper 只在 j+1<oh 时调用。最大输入行为 j+kh，且 j<=oh−2，因此 j+kh<=oh+kh−2=inputHeight−1。未成对的最后一行由原 prefix 处理。
- 主块条件 i+4×VL<=ow。最后偏移 1 加载最大输入列 i+ik+4×VL<=ow+kw−2=inputWidth−1；没有额外加载完整 v4。每行最后输出 i+4×VL−1<ow。
- 两输出目标区间分别是第 j 与 j+1 行，彼此不重叠，各行对由唯一 OpenMP 迭代拥有；没有共享写或跨线程求和。
- VL 每个工作线程自行查询，不固定为512位、不按官方尺寸分支。

## 风险与待验证内容

半宽主块可能增加遍历/首尾循环成本；同时广播两行系数可能增加寄存器压力；较少行对也可能在很矮的输入上减少并行度。共享加载是源码事实，是否生成更少指令或提升速度须以目标汇编及测量判断。

本机仅轻量编辑、静态阅读与元数据登记，未编译或执行任何题目测试。由主代理在调度计算节点按原 runner 设置编译、保护页与独立标量参考检查，重点包括 kh=1/2/3及偶奇、oh=1/2/3及偶奇、kw=1/偶奇、4×VL周围与各种尾部、多VL和1/4线程，检查真实双行 SVE 路径。

所有正确性通过后，与 C13-r5 同资源分配测量三轮完整官方套件并保存逐项样本、波动、汇编和退化记录。当前只 prepared，不宣称正确或提速，未晋级。
