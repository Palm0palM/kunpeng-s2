# C17-pipe16：十六累加器配合流式输入复用

- 父测量为 C13-r3，源码基线为 C3（C13-exttail）。扩展采用同轮 C16-pipe12 的流式写法，但比较父记录仍是已晋级基线。
- 单一假设：旧 C9 十六向量实现出现热循环寄存器溢出；这次只保留当前/下一输入的源码流式写法，验证能否以十六累加器摊薄循环/广播开销而避免旧实现的溢出。寄存器分配和速度均须实际汇编与计时确认。
- 仅改变 conv_sve_prefix：主块为 `16 * svcntw()`，累加器 a0～a15 跨整个 kernel 保持。前十五个向量通过 `svext(current, next, 1)` 复用第二个输入，最后向量第二个输入从 `p + 15 * lanes + 1` 直接加载，不加载完整 v16。每对系数 17 次输入向量加载、15 次拼接。
- 当前/下一输入仍可能被编译器重调度，十六累加器也会提高寄存器压力；降低输入生存期不能保证不溢出。
- 不改 SVE 尾部、通用回退、单线程输出归属、官方 runner/benchmark、精度容差、浮点约束；不识别官方输入尺寸。

## 静态数值与范围推导

- 每个输出仍按 jk、ik 升序，依次执行 k0 的乘法/加法和 k1 的乘法/加法；各输出相互独立，未拆分 partial sum、重括号或引入 FMA。
- 双系数循环满足 `ik <= kw - 2`。`kw=1` 跳过此循环；偶数 kw 恰好全部按对处理；奇数 kw 用单系数循环处理最后一个系数。
- 主块条件 `ow - i >= block` 确保 `i + block <= ow`，最后输出下标 `i + block - 1 < ow`。
- 最后偏移 1 输入向量末列是 `i + ik + block`，不超过 `ow + kw - 2 == inputWidth - 1`。普通相邻输入加载末列最多 `i + ik + block - 1`。没有在有效窗口之外额外读取完整第十七向量。
- 奇数 kw 最后一系数的末列是 `i + (kw - 1) + block - 1 <= inputWidth - 1`。最后输入行仍是 `j + kh - 1 < inputHeight`。
- 每个工作线程获取自身 `svcntw()`，全部偏移和 block 随 VL 改变，不固定 512 位。
- 原尾部函数的四向量 while 可重复处理 12～16 向量之间余数，随后二向量 while 与单个掩码向量覆盖不足的部分；主块后零余数不会调用尾部。
