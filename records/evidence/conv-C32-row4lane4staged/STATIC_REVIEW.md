# C32 静态审查

对 C29 父源码进行文本差异审查，唯一新增块位于四系数共享循环 n=1/lane3 之后、n=2/lane0 之前；八个输入按 a0,b0,c0,d0,a1,b1,c1,d1 顺序，约束全部为 `w`，clobber 仅 `memory`，asm 模板为空且 volatile。

其余源码由 experiment new 从父快照复制；静态差异中没有其它增删。四系数加载、全部64次乘法及64次加法的原表达式、两个余数循环、其它阶段与 helper、调度和非 SVE 路径保持不变；三个非算子源文件保持父快照内容。没有新增地址、步长、内存读写、运算或分支，不扩大原边界。

本审查不表示编译、正确性或性能通过。实际 compiler 接受性、寄存器分配及性能等待根代理安排超算验证。
