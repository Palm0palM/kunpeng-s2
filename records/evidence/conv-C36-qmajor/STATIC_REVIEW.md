# C36-qmajor 静态范围、顺序与边界审查

审查对象为 C26-row4loads → C36-qmajor；仅处理源文本，不执行编译或算子测试。

1. **不是已有排列：** 父版本中每个 aN/bN/cN/dN 的 ik/ik+1 更新连续出现；候选才改为先完成所有16个 ik 更新，再完成所有16个 ik+1 更新。
2. **变更范围单一：** 差异仅在 quad 共享中段双列循环内的输入声明与更新排列，并增加两条阶段注释。八个系数声明在差异范围前保持原文；单列余数及循环之后文本保持原文，循环之前文本也保持原文。
3. **没有丢失或重复项：** 用源文本逐句核对，候选与父版的八条 `svld1` 声明和32条 `svadd(...svmul(...))` 更新语句多重集合相同。每个 vN 只配 k0，每个 xN 只配 k1；a/b/c/d 系数各自对应原输出，不交换行。
4. **每输出顺序不变：** 第一阶段先更新该累加器的 ik 项，第二阶段用更新后的值加 ik+1 项。其它输出的独立更新插入两项之间，不改变同一累加器的运算树、乘法或加法顺序。跨 ik、跨 t 和奇数余项顺序均保持。
5. **无新地址：** 原八个 load 表达式原样保留。由 ik+1<kw 与 i+4*lanes<=ow，最后 x3 窗口末列不超过 inputWidth−1；不形成或读取完整 v4。垂直范围仍为原 j+t，共享阶段 t<=kh−1，首尾行范围未改。
6. **泛化与线程：** kh<4、kw=1、奇偶 kernel、可变 VL、窄输出、尾列及尾输出行全用原分派/余数条件。无官方尺寸分支；OMP 分组和各输出写入范围未改，无新增跨线程共享可写状态。
7. **其余文件：** `bench_conv.c`、`run.sh`、源码 `README.md` 保持父快照，只有新候选 `conv2d.c` 改动；没有修改已有 C35 或正式源码。

静态结论：未发现丢项、错配系数、浮点累加次序变化或扩大访问范围。GCC 仍可合法调整独立指令，实际排布可能与父版相同；是否改善加载/计算调度、是否出现 spill、是否获益均待超算。不能把本页的源文本核对称为已编译或正确性通过，候选只登记 prepared。
