# Root partition design obligations before AX

For total T tiles and actual team P>0, quotient q=T/P and remainder r=T%P. Worker t in[0,P) receives begin=t*q+min(t,r), count=q+(t<r), end=begin+count. Each next begin equals prior end, first begin0 and last endT, so intervals partition[0,T) without overlap even whenT<P. Avoid T*t multiplication. With positive32-bit output dimensions, groups<=oh and tiles_per_group<=ow; T<=INT_MAX^2 fits AArch64 size_t. Width products stay size_t until capped toow before int conversion.

Mapping linear tile to(group=floor(tile/K), column tile=tile%K), K=ceil(ow/block), gives one-to-one rowgroup/column coverage. Coalescing worker interval up to min(worker_end,(group+1)*K) cannot cross rowgroup or another worker. Column end is capped toow; nonempty tile interval remains nonempty in real columns. Each output belongs to exactly one rowgroup and column interval. Helpers write disjoint output rows for row tails by the original branch decomposition. This mathematical proof must be matched to actual C65 source; it is not a measured runtime claim.

All workers must use a common positiveblock for this partition. A sharedblock selected by omp single with its implicit barrier is valid; each helper may use its own SVE vector length but can handle arbitrary positive interval width. AX verifies uniform actual VL in its team to independently predict helper-entry counts. A target-SVE query must only run after HWCAP_SVE, and generic conv2d must not inline unsupported target intrinsics. Non-OpenMP builds must use one logical worker without unresolved omp symbols.

AX proposed finite scope is original5744 guard cases,2724 dispatch including1512 new balance cases,432 direct per config; VL16/32/64 bytes times1/4/38threads gives80100 and25 stages. The separate diagnostic svst1 observer must preserve original writes/predicates, count all active output lanes atomically, reset per case and check after team join. Bitwise PASS alone cannot prove absence of duplicate equal-value writes. All production helpers/reference/runner and strict FP order remain immutable for this hypothesis. Only target scheduled nodes compile/run,1800second cap retained.
