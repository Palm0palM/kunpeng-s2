# CONV C5 提交包

下载 [conv.zip](conv.zip)，选择比赛 CONV 题目后原样上传。无需重新压缩版本目录，也不要把外部说明文件压入 ZIP。

当前最佳 **C5 = C21-r2**，源码方案 **C21-row3x4**：三个相邻输出行各使用四个 SVE 向量，共十二个累加器，共享输入行加载；每个输出保持原 kernel 行、列顺序以及独立乘法和加法。小卷积核、尾部列和剩余输出行使用已验证的回退路径。

同一 38 核单 NUMA 分配内，C4 对照 **C19-r7** 从 **561.60 ms** 降至 C5 **502.20 ms**，耗时减少 **10.58%**。这些数值是三轮完整套件的四项中位数合计，属于内部比较指标，**不是官方分数或排名**。

最终同一 ZIP 已在计算节点作业 **1519750** 校验哈希、解压并逐文件核验，再运行三轮完整官方套件：12/12 PASS，最大误差 0，四项中位数合计 **502.29 ms**。包验证是独立资源分配，不与其他分配直接计算提速。

ZIP 恰含 `conv/README.md`、`conv/bench_conv.c`、`conv/conv2d.c`、`conv/run.sh`；runner 保留执行权限。官方 benchmark、runner 和源码 README 保持不变。包按已验证原件逐字节复制，本机只做文件整理与身份核对，没有运行题目。
