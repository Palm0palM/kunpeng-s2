# CONV C2

**当前最佳，上传本目录的 `conv.zip`。** 包内是 `conv/` 下四份已测源码和运行文件，无需重新压缩。

- 来源：`C8-r1` 复测，初次晋级实验为 `C8-sve128`，两次源码相同。
- 策略：八个显式 SVE 寄存器累加器，实机主块 128 列；保持原数值累加顺序，非 SVE 机器走通用回退。
- 超算结果：四项中位耗时合计 **629.91 ms**；3 轮完整官方套件、12/12 PASS，最大误差 0。
- 环境：GCC 10.3.1、38 线程、单 NUMA、`generic`，禁用 fast-math 和 FMA contraction。
- 以上是内部性能指标，不是比赛分数。官方 benchmark 与校验未改。
