## C32 专项已通过

[C32-row4lane4staged](../records/experiments/conv/C32-row4lane4staged.json) 的源码来源为 C29-row4lane4。唯一算子变更是在 quad 四系数循环完成 n=0/1 的八个累加器后、n=2 的输入加载前插入一道空 volatile asm，输入为 a0/b0/c0/d0/a1/b1/c1/d1，全部使用 `w` 约束，clobber 仅为 `memory`。系数加载、浮点表达式及顺序、余数、其它 helpers、调度、benchmark 和 runner 均保持父版。

专项作业 **1579286** 已 SUCCEEDED，调度器、系统及包装器退出码均为0；冻结的 validation.json 为 complete=true、status=passed。1/4线程 × 128/256/512位 SVE 六配置，每配置20,164项完整检查加96项真实入口 smoke，合计 **121,560项全部通过**。实际 VL、各可达 helper、只读 input/kernel、保护页、输出预填/canary及有序 scalar 逐位对照通过。自动传输清单与远端执行记录一致，未追加重复人工哈希审计；sanitizer 未运行。

目标 GCC 10.3.1 严格浮点汇编中，quad 四系数共享热点 `.L342` 实际结果如下。每次迭代处理四个 kernel 列，表中数量不能与单列/双列循环直接比较。

| 观察项 | C32 实际结果 |
| --- | ---: |
| 主循环指令 | 159 |
| indexed FMUL / 独立 FADD | 64 / 64 |
| 输入 LD1W / 系数 LD1RQW | 16 / 4 |
| 普通向量 MOV | 3 |
| 向量 spill 读取 / 写入 | 0 / 0 |
| EXT / MOVPRFX / dup | 0 / 0 / 0 |
| 全源码 FMA | 0 |

C29 每四列迭代的2次向量 spill 读取和2次写入已在 C32 实际汇编中消除；所列双列内循环也无 spill，整个 quad 无 Z/Q 寄存器栈读写。固定栈帧784字节，不再附加2VL；ABI 的 d8–d14 保存和外围标量状态不计作累加器溢出。64次 indexed FMUL 的系数都位于低 Z0–Z7，每个 lane 使用16次。

这些观察已由独立静态审查复核，证明实际编译调度改变；实际性能却比本轮同分配 C6 慢10.62%，因此无 spill 不能作为晋级依据。屏障可能影响提前加载与流水重叠，普通 MOV 也有成本，但本轮没有同分配的 C29 对照，**不能将不同 allocation 的 C29/C32 耗时直接换算为屏障的因果百分比**。

## 探索性性能结果

作业 **1579297** 已完整回收，campaign 状态 performance_complete。四成员在同一38核单 NUMA 分配内按预定顺序各执行三个独立完整套件；记录均 status=passed、verified=true，共 **12套件、48/48 PASS、最大误差0**。

四项顺序为：输入4096×6144 / 核39×39，6144×4096 / 核41×41，4256×6390 / 核55×55，6390×4256 / 核81×81。波动为该成员四项中最大的 `(最大值−最小值)/中位数`；耗时降幅的正值表示更快。

| 顺序 | 成员 | 四项中位数 ms | 合计 ms | 最大波动 | 对关闭 C6 的耗时降幅 | 判定 |
| --- | --- | --- | ---: | ---: | ---: | --- |
| 1 | [C26-r4](../records/experiments/conv/C26-r4.json) | 51.38 / 61.95 / 107.30 / 231.74 | 452.37 | 0.08071% | — | 开场不变 C6 |
| 2 | [C30-r1](../records/experiments/conv/C30-r1.json) | 50.97 / 61.31 / 106.50 / 229.25 | 448.03 | 2.18561% | +0.972526% | eligible=false；低于最低门槛及自身波动 |
| 3 | [C32-row4lane4staged](../records/experiments/conv/C32-row4lane4staged.json) | 56.79 / 67.08 / 119.19 / 257.43 | 500.49 | 0.91565% | -10.622638% | eligible=false；四项均退化 |

C30-r1 与 C32 的比较 parent / comparison_baseline 均在运行前固定为 **C26-r5**，source_parent 分别保留 C30-colchunks、C29-row4lane4；开场 C26-r4 作交叉检查。

**C30-r1 不合格。** 相对关闭 C6 的452.43 ms，448.03 ms对应降幅 **0.972526%**，既低于最低1%，也没有超过自身最大波动 **2.185614%**。不能通过删除慢样本提高通过概率，也不能将前轮或本轮较有利的样本重新拼成一次确认。

**C32 不合格。** 500.49 ms比同分配关闭 C6 慢 **10.622638%**；四项分别退化10.4219%、8.2809%、11.0604%、11.0905%。专项正确性及实际 spill 消除仍成立，但不抵消这份性能退化结论。
