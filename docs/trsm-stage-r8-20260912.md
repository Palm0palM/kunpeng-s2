# TRSM 第八轮：8×16 SVE 大路径更新

**保留 T8-svepanel16，T11 暂不晋级。** 同分配三轮中，T11 大矩阵用例的中位数减少 3.57%，但三例中位数合计只减少 0.38%，未超过 11.52% 波动门槛，另外两例分别慢 1.34% 和 2.27%。这是一组值得确认的大路径结果，尚不足以认定整体稳定提速。现有已验证 T8 ZIP 保持不变。

## 改动与实际环境

T11-sve8x16 从 T8 派生，只改变大工作集的完整 16 列更新：每个 8×16 微核用同一个 L 系数更新两组 8 列累加器。保留递增 k 的零基 FMA 链、最后一次 C 减法、KB=256、CT=64、共享面板布局、线程分工及尾部回退；小工作集实现未改。没有修改官方 benchmark、runner、输入、精度或计时区。

作业 **1579444**，2026-09-12 17:18:16 提交，17:23:16–17:26:00 执行，调度器 SUCCEEDED、作业/系统/cohort/成员退出码均为 0。实际节点 cn22965，单 NUMA 3，CPU 114–151，38 线程、24GiB、1800 秒上限。GCC 12.3.1，generic target，无 fast-math，关闭隐式 FMA contraction，保留显式 FMA。

使用真实 Huawei KML 25.1.0 头文件和默认 `-lkblas`，私有 GCC12 OpenMP 运行库；探针与各套实际动态依赖检查通过。**这不是指定 KML 25.2.0 的复验，也不是 OpenBLAS 校验。** 与旧轮次的不同 NUMA、编译器或参考库耗时不混算收益。

测前固定协议为：每成员先执行一套完整原官方 warm-up，然后按 AB/BA/AB 各执行三套完整正式用例；每套 `TEST_RUNS=3`。下表每个样本是 benchmark 内部三次的平均毫秒数，中位数来自三个独立正式套件。全部正式样本保留，未删除慢样本。

## 新核和回退验证

两成员各通过原通用预检：14 组直接小核、406 组整算子、28 组空操作检查。T11 另通过 28 组 8×16 直接核检查：k=0/1/2/7/31/255/256，两种 L 步长、packed/strided X 两种布局，按独立递增 k 显式 FMA 参考逐位比对，完整 L/X/C padding 和前后 guards 保持。

补充大路径共 8 次检查，覆盖 4105×25、4111×31 的行列尾部和非紧密 lda/ldb，正常 1/4/38 线程，以及共享 packed 分配失败、无 SVE、实际 16-byte 窄 VL。正常和共享分配失败时均实测新核入口 3856 次；无 SVE 和窄 VL 时为 0。共享分配只注入一次失败，并确认仍使用 strided X 进入新核。最大已知解误差 3.33e-16，最大残差 7.29e-16，L/B padding 保持。稠密结构下三角 fixture 的长双精度前缀参考仅作补充，没有替代通用预检或官方用例。未运行 sanitizer。

实际目标汇编中，新核每 k 为 39 条指令，旧 16×8 核为 52 条；均计算 128 个输出、16 次向量 FMA，没有热循环栈读写或调用。等价 16×16 更新的 L 系数读取从 32 个降到 16 个，X 向量读取从 2 个增到 4 个；架构输入字节数相同，不能称总带宽减半。新核回写指令也更多。详见[目标汇编审查](../records/evidence/trsm-stage-r8-20260912/cohorts/compare/assembly-review-wide8x16.md)。汇编解释了代码生成变化，性能结论仍以上述实测为准。
