# TRSM 第二十二轮：显式广播加载没有得到稳定收益

继续保持 **T19-panel8x16budget**。T24 仅将小路径 8×16 历史循环的八个系数加载改为显式 `LD1RD`，随后用向量系数做同顺序 FMA；单步循环、16 条累加链、块内前代、预算、分配和完整大路径保持 T19。中用例只快 **0.40%**，中位数合计快 **0.29%**，低于 **10.61%** 波动门槛，不晋级。

作业 **1582526** 成功结束，用时 525 秒。同一计算节点、NUMA 2、CPU 76–113、38 线程；A=T19、B=T24，独立预热 AB 后按 AB / BA / AB 各执行三套完整官方用例。每套 `TEST_RUNS=3`，每个样本是 benchmark 内部三次计时的均值。

|版本|512×19968 三轮 ms|2432×17024 三轮 ms|17024×512 三轮 ms|中位数合计 ms|
|---|---|---|---|---:|
|T19-control13|14.40 / 15.98 / 14.89|119.44 / 121.40 / 127.95|180.68 / 180.68 / 180.41|316.97|
|T24-smallbroadcast|14.35 / 13.58 / 14.14|118.95 / 121.43 / 120.92|180.36 / 181.12 / 181.00|316.06|

相对同期 T19，小/中/大例耗时减少为 **5.04% / 0.40% / −0.18%**。小例仍走预算内的 packed-history 路径，不调用本次修改的 8×16 核，因此它的差异不能归因于新广播加载。保留全部样本，包括 T19 的 15.98 和 127.95 ms，不删除慢样本或合并历史时序。晋级仍要求合计改善超过双方逐例最大相对波动及 1%，并且每例退步不超过 1%；合计只是内部指标，不是官方得分。

18/18 正式、6/6 预热结果均 PASS，最大误差 1.11e-15。两版都重新通过完整小路径预检：各 37 个步骤、27 个测试进程、46 个直接微核、615 个整算子、96 个 no-op、32 个预算组，633 个参数检查用例累计 6388 次观察无不匹配。覆盖零/一/奇偶历史、padding、L 只读、预算边界、行列尾项、禁用 SVE、窄向量和共享/X/全部分配失败；预检最大误差 3.88578e-16。

原源码目标汇编验证了加载改动，但热循环仍为每步 **37 条指令、16 条 FMLA**：T19 的 8 条 LDR + 8 条 MOV，变成 T24 的 8 条 LD1RD + 8 条额外地址 ADD。两者均无热循环栈访问，ABI 栈帧均为 32 字节。指令类型变化没有转化为稳定提速；不能凭“减少广播复制”就判定优化成功。

实现依据：[ACLE](https://arm-software.github.io/acle/main/acle.html#sve-ld1r-instructions) 没有单独 LD1RD intrinsic；[GCC 约束](https://gcc.gnu.org/onlinedocs/gcc/Machine-Constraints.html) 的 w/Upl/Q 用于输出向量、输入谓词及单基址内存。[GCC12 asm 规则](https://gcc.gnu.org/onlinedocs/gcc-12.3.0/gcc/Extended-Asm.html) 要求准确声明访问的内存。本候选每条 asm 明确输入一个 double，不加入额外内存屏障；实际 GCC12 编译、直接微核与整算子检查均通过。

实际环境为 **KML25.1 真头文件和动态库、GCC12.3.1 及配套 libgomp**，参考探测和每套依赖检查通过；**不是指定 KML25.2.0 复验**。官方 benchmark、输入、精度、线程限制不变，无本机题目运行、sanitizer 或哈希操作。完整 T19 prior 关联第二十一轮作业 1582392，见[源码、原始结果脱敏副本、环境、命令、prior 与汇编](../records/evidence/trsm-stage-r22-20260913/README.md)。
