# CONV 迭代记录与公开导出

每个优化假设建立独立 C 版本，保存父版本、策略、源码 SHA、完整环境与命令、每组原始耗时、正确性、三轮中位数和比较结论。失败、退化、超时与未完成候选都留档。经同环境实测确认提速才晋级；相同源码复测使用 C0-r3 一类后缀，不虚增优化版本。

`tools/experiment.py` 维护原记录，`.runs/conv/<版本>/` 保留原始证据。发布前运行以下导出器，输出必须是不存在的新目录，不能放在源码或原记录目录内：

```bash
python3 tools/export_conv_records.py --output /private/tmp/conv-public-round --versions C0-r3 C0-r4 C4-b24 C5-b48 C6-row2
```

后续版本以完整 ID 追加到 `--versions`，例如 `C7-b16`、`C0-r5`，不接受通配符。不传版本列表时仅导出本轮默认五版。导出器只读取原记录与配置，不更新基线、不修改原件、不推送 GitHub。

新目录包括实验 JSON、中文逐版本速度表、远程与本地文本证据、候选相对父源码补丁，以及 `PUBLICATION-CONV.md` 和双哈希 manifest。账号、个人路径、私网地址和内部节点在公开文本中脱敏；配置与占位符映射不发布。原始 SHA 字段保持原值，公开文件用 manifest 的 `public_sha256` 核验。候选补丁生成前会核实父与子源码 SHA。

发布者把新目录中的文件合并到干净发布工作树；逐项查看差异，保留现有最佳题解和其他人的改动，再按用户授权推送。运行中的实验可重复导出到新的目录，旧导出不覆盖。公开副本不能代替本地原始证据参与自动晋级。
