# CONV 2026-09-09 优化记录

从已晋级 C2（C8-r1）开始；此页只记录本轮，之前的晋级台账和最佳提交包保留。

| 实验 | 假设 | 状态 |
| --- | --- | --- |
| C8-r2 | C2 原源码同资源复测 | 三轮完整官方套件已提交 |
| C10-svetail | 八向量主块保持原样，尾部用 4/2 个完整 SVE 向量与最后的掩码向量 | 边界通过，性能待测 |
| C11-sveext | 每对 kernel 元素的输入加载从 16 次降到 9 次，新增 7 次向量拼接 | 边界通过，性能待测 |
| C12-sveu1 | SVE 主块从 kernel 双步展开改为单步，减少同时存活的临时向量 | 边界通过，性能待测 |

三种候选分别基于同一 C2 源码，只修改对应实验 source/conv2d.c。官方 benchmark、run.sh、精度容差、累加次序及分离乘法/加法均保持不变。性能组使用同一个 38 核单 NUMA 调度作业，每个版本独立运行三轮完整官方套件。

三个候选分别完成本机 1/4 线程 UBSan 加保护页检查，每次 880 组、逐位匹配独立标量参考。真实鲲鹏上完成默认向量长度 1/4 线程，以及 128/256/512 位向量长度的四线程检查，每次 880 组；带函数入口插桩的构建确认进入 SVE 路径。服务器没有运行 sanitizer。

原件保存在各实验的 .runs/conv/<版本>/local/、sve-correctness/ 和 benchmark.log；候选未通过同环境速度筛选前不晋级。耗时仅作内部比较，不是官方分数。未向比赛平台提交。

## 第一批完整测量

四个版本共享同一个 38 核单 NUMA 分配；作业成功，48 行官方用例全部 PASS，误差为零。

| 版本 | 四组中位数合计 ms | 相对同组 C2 | 判断 |
| --- | ---: | ---: | --- |
| C8-r2 | 631.13 | 基线 | 第一组跨轮波动 8.66% |
| C10-svetail | 620.40 | 耗时减少 1.70% | 收益低于基线最大波动，待复测 |
| C11-sveext | 613.04 | 耗时减少 2.87% | 收益低于最大波动，待复测 |
| C12-sveu1 | 643.28 | 耗时增加 1.93% | 未晋级；保留退化结果 |

第二批固定到历史已测节点，使用同一资源分配，顺序为 C2 → 输入复用 → 组合 → C2 → 组合 → 输入复用；每项仍为三轮完整套件。组合 C13-exttail 只叠加前两种独立改动，主块尺寸和数值路径不变。节点名及作业连接原件留在本地记录中。

历史节点暂不可用，调度器不支持清空节点偏好；在作业开始前将同一作业改到第一批测量节点。未重复提交，资源与输入未改变。原提交与两次调整的命令、返回信息都已保留。

用户在本轮明确要求后续不在本机运行题目。此前的本机检查已经结束，之后所有编译与测试只在超算计算节点进行；本机只编辑、传输和整理记录。此偏好已写入工作区和本仓库 AGENTS.md。

第二批作业成功完成，共 72 行官方用例 PASS，最大误差均为零。六个记录均通过调度器、包装器、源码身份与环境核对。

| 版本 | 四组中位数合计 ms | 用途 |
| --- | ---: | --- |
| C8-r3 | 631.31 | 前半段 C2 基线 |
| C11-r1 | 609.89 | 输入复用 |
| C13-exttail | 590.36 | 输入复用加 SVE 尾部 |

组合方案相对前/后基线分别减少约 6.49% / 6.52% 耗时，四组均改善。组合方案两次都超过对应基线及候选的测量波动，晋级为 C3，实验来源 C13-exttail。晋级前将父记录改为同作业实测的 C8-r3；其源码与原父 C8-r1 完全相同，保留 source_parent 字段说明来源，没有更改源码或测量值。

最后再以 C3 为基线验证 C14-ext4 四系数复用；若没有稳定新增收益，保留 C3。最终 ZIP 仍需单独验证，完成前保留旧提交包。

## 最后一种尝试

C14-ext4 将输入复用从两系数扩大到四系数，保护页及三种 SVE 长度校验通过，官方大用例也全部通过，但性能退化。与同作业 C13-r2 基线对照，四组中位数合计从 591.44 ms 增至 739.47 ms，慢 25.03%；四组均退化，因此拒绝晋级。保留完整源码、边界验证、汇编、命令、原始日志和失败结论。

本轮最终实现为 C3（C13-exttail）：保持八个 SVE 累加器，成对 kernel 元素通过向量拼接复用输入，尾部采用 4/2/1 SVE 向量及掩码处理。对每个输出的乘法和加法仍逐项按参考顺序执行；官方 benchmark、runner、输入、线程上限和容差均未改动。

| 官方用例（输入 / kernel） | C2 中位数 ms | C3 中位数 ms | 耗时减少 |
| --- | ---: | ---: | ---: |
| 4096×6144 / 39×39 | 69.13 | 66.17 | 4.28% |
| 6144×4096 / 41×41 | 88.86 | 81.26 | 8.55% |
| 4256×6390 / 55×55 | 146.77 | 137.87 | 6.07% |
| 6390×4256 / 81×81 | 326.55 | 305.06 | 6.58% |
| 合计 | 631.31 | 590.36 | 6.49% |

表中是同一次资源分配内三轮独立完整套件的逐用例中位数。后半段换序后的同源码复测为 C2 631.37 ms、C3 590.17 ms，支持相同结论。合计不是官方评分。
