# CONV：七行、三向量候选的专项验证

C51-row7x3u1 基于 C40-row6x3u1，将每组输出从六行改为七行，每行仍为三个 SVE 向量，使用 21 个独立累加器。每个输出保持原 kernel 行/列累加顺序、独立乘法和加法；只改专用 helper 与分派，benchmark、runner 和旧 helper 保持原字节。

超算作业 **1581822** 已完成，GCC 10.3.1 接受并执行；scheduler、job/system、wrapper 和全部 19 个作业阶段均正常退出。SVE 16/32/64 字节 × 1/4 线程六配置共 **37128/37128 PASS**，包括每配置 4784 项生产检查、972 项分派检查、432 项直接调用小 kernel 防御分支。使用独立逐项 scalar 参考并逐位比较，输入/权重只读，分配边界 guard、输出 poison 和外围 canary 全部通过。

每配置实际七行 helper 入口数为分派 756、直接调用 1080；每 case 检查入口增量，线程 mask 分别为 1/15。mask 和旧 helper 非零入口是各套件累计证据，不是每阶段动态覆盖证明。最终矩阵集中检查七行阈值、所有余行与 3VL/6VL 边界；未执行原建议额外的 L/2L 邻域 864 项，也没有 direct 的 ow=1、invalid-dimension、屏蔽 SVE、NaN/Inf 专项或 sanitizer。完整范围见冻结目录的 INTERFACE 与独立检查器审查。

十三个算术阶段每轮指令数为 14/23/31/39/47/55/63/55/47/39/31/23/14，全部阶段、转换、21 个输出 store、横向 quad+triple 尾部与 kh<7 防御路径均按实际产物审查。保留的是未插桩生产 `.s`，没有生产 `.o`，不宣称对象反汇编一致。

根代理另行检查所有 conv2d/OMP 分派：新七行 worker 栈帧 240 字节，余六行 quad+pair、余五行 quad+prefix，其余旧 helper；原四行 worker 与公共入口均为 160 字节，没有向量/谓词写栈。非 SVE worker 的完整实际文本与此前独立审查的 C47 完全一致，包含原 368 字节栈帧与局部 tile 的向量写栈，不能把它误称为七行 SVE 累加器 spill。

诊断通过和零 spill 均不证明提速。随后 [R 原 benchmark 对照](CONV_SEP13R.md) 独立测得 C51 为 438.95 ms，比结束 C6 的 452.28 ms 减少约 2.95%，达到两端初筛门槛，仍须独立确认和最终原 ZIP 验证。C40 只作形状参考，不改写其原 G/J/K 判定。诊断原件保留冻结时尚未测速的状态，后续测量另存；当前正式最佳仍为 C6，没有创建新提交包。

首次状态查询遭到本机沙箱网络限制的原始失败记录也已保留；随后用已有授权查询和取回同一作业，没有重新提交。全部算子编译和测试只在超算调度节点执行，没有使用重置卡。
