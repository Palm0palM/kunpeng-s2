## 数值与边界约束

每个输出始终按照 kernel 行、列升序累加，双系数循环先 k0 后 k1，乘法与加法分离，不启用 FMA 或 fast-math、不合并部分和、不修改容差。各候选使用当前工作线程的实际 VL，不固定为 512 位，也不识别官方输入尺寸。

C20 保持原两行调度与首/中/末输入行分工。六向量主块最后 k1 窗口从 `p+5×VL+1` 读取，最大列不超过输入行尾，未额外读取完整第七向量；不足六向量余数交回原 prefix/tail。

C21 的五阶段分别处理输入行 0、1、2..kh−1、kh、kh+1，使三输出行各自仍恰好接收 kernel 行 0..kh−1。kh=1/2 回退原 rowpair 与 prefix；剩余一/两输出行也使用原 helper。三行组数量用 `oh/3+(oh%3!=0)` 计算，避免 oh+2 溢出；最大输入行不超过 `inputHeight−1`，各组写入互不重叠。

C22 只替换三处输入窗口的取得方式，各 lane 的值与原拼接一致；累加、接口、调度和最后窗口不变。目标汇编已确认共享中段去掉了原 C4 的三次 ext 和三次 movprfx，同时输入加载从五次增为八次；是否因加载增加而变慢仍须实测。
