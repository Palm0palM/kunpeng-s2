# CONV 2026-09-12 第四轮：C33 五行共享

**正式最佳仍为 C6 = C26-r1，来源 C26-row4loads；C33首测比同分配C6慢3.26%，不晋级。** 当前继续使用 [已发布 C6 原包](https://github.com/Palm0palM/kunpeng-s2/blob/b5ef7ea27958b1531feadf3cc50f66a23c3a02f4/conv/result/C6/conv.zip)。此前完整尝试见 [SEP12B](CONV_SEP12B.md) 和 [SEP12C](CONV_SEP12C.md)，旧样本及判定保持不变。

## 方案与复现条件

[C33-row5x4u1](../records/experiments/conv/C33-row5x4u1.json) 从 C26-row4loads 源码增加 `conv_sve_rowquint`：五个相邻输出行各四个 SVE 向量，共20累加器；kernel 列单步推进。输入行阶段为0、1、2、3、4..kh-1、kh、kh+1、kh+2、kh+3；输出 r 在参与时使用 kernel 行 t-r，各输出严格保留原 kernel 行列顺序及独立乘/加。

只有 SVE 可用、kh>=5且至少5个输出行时使用五行组；最后4/3/2/1行调用原 quad/triple/pair/prefix，行间输出指针保持全局 ow。小核及不足5行完整走原 C6 分派，旧 helpers、非 SVE、benchmark、runner、源码 README 和容差均未修改。理论共享中段输入加载率约减少20%、每单位系数广播率不变，但内层回边率约增加60%；更多边界阶段和线程尾部不均可能抵消收益。

复现应使用 C33 实验记录指定的源码快照及其原 runner，不能以当前正式 conv/ 的 C6 源码替代。目标编译沿用 GCC10.3.1、`-O3 -fno-fast-math -ffp-contract=off -mcpu=generic -fopenmp`，SVE helper 保留函数级 target 属性；不修改参考或计时区。性能对照采用相同38线程、单 NUMA绑定及四项公开输入，各成员三个独立完整套件。三套件不同于 benchmark 内部的 TEST_RUNS，实际配置与原始运行记录一起保存。

## 专项诊断已通过

原专项作业 **1579312** 已 SUCCEEDED，调度器、系统、包装器退出码均为0；没有重提。冻结结果位于本地实验的 `sve-correctness-sep12d`，validation 为 complete=true、status=passed；自动传输清单与远端执行源码相符。

1/4线程 × 128/256/512位 SVE 共六配置，每配置 **40,804项完整检查 + 864项入口 smoke**，总计 **244,824 + 5,184 = 250,008项全部通过**。检查实际 VL/线程、每行4VL主块、保护页、只读 input/kernel、NaN预填输出/canary及有序 scalar 逐位参考。kh4/5/6边界、五行组余1..4行、多个 VL 的宽度边界均覆盖，oh20包含四个worker的五行工作。sanitizer 未运行。

每个配置真实入口次数如下；这些是 helper 调用次数，不额外计入250,008项：

| helper | 每配置入口次数 |
| --- | ---: |
| prefix / tail | 各7,920 |
| pair | 768 |
| triple | 1,776 |
| quad | 1,632 |
| 新 quint | 432 |

目标 quint 共享单列热点 `.L417` 实际为 **58条指令：20次 FMUL、20次独立 FADD、4次输入 LD1W、5次系数 LD1RW**。九个单列阶段指令数依次为17/28/38/48/58/48/38/28/17，均无向量spill、EXT/MOVPRFX/dup。整个 quint 无 Z/Q 寄存器栈读写，固定528字节帧无额外VL空间；d8–d11属于ABI保存，全源码 FMA为0。`.L418`属于外层共享输入行循环，不重复统计成列阶段。

上述结果证明实际编译和专项正确性通过，**不能据此推断提速**；单列工作量也不能直接用原始指令数与双列、四列方案比较。未增加重复人工哈希审计，全部原始证据保留。

## 首次性能结果

作业 **1579358** 已完整回收，调度器、系统及包装器成功；三成员各三个完整套件，共 **9套件、36/36 PASS、最大误差0**。C26-r7 是运行前指定的主要关闭控制，C26-r6 开场交叉检查；两份控制都是无 parent 的不变 C6。
