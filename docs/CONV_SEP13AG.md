# CONV C57：显式 FMA 未通过官方精度

C57 基于 C52，只把 shared 两列主循环及单列余项的63个乘加表达式改为显式 SVE FMA。原作业1583276在未修改的官方 benchmark 下运行四个尺寸×三套：**12/12 FAIL**，因此保留 C6，未生成提交包。

| 用例 | 三套均打印的最大绝对误差 | 官方容差 |
|---|---:|---:|
| 4096×6144，39×39 | 1.53e-4 | 1e-5 |
| 6144×4096，41×41 | 1.83e-4 | 1e-5 |
| 4256×6390，55×55 | 3.66e-4 | 1e-5 |
| 6390×4256，81×81 | 6.10e-4 | 1e-5 |

三套使用官方固定种子，误差精度按原打印保留。失败发生在计时前，未获得可比较耗时。官方进程失败时仍返回0；包装器根据FAIL判定全部失败，最终job/wrapper退出1、system10001。构建和两份汇编生成成功不代表正确性通过。

实际环境为 GCC10.3.1、generic、strict浮点、38线程、单NUMA计算节点。实际候选汇编包含63条FMLA；官方参考仍为分开的FMUL/FADD，参考汇编融合指令0。本结果证明这次融合改法不满足题目原精度要求，不推断所有FMA算法均不可用。

首次状态查询遇到本机沙箱网络限制，已保留该输出；之后仅恢复查询原作业并首次取回结果，没有重复提交。全部原日志、失败原因和策略保留在版本记录中。本机未编译或运行算子。
