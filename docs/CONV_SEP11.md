# CONV 2026-09-11 优化记录

本轮已从 C3 晋级到 **C4**。最后一次同资源对照中，四项中位数合计从 **591.29 ms 降至 561.54 ms，耗时减少 5.03%**；四项均改善，最大误差均为 0。基线与候选的最大跨轮波动分别为 0.89% 和 0.34%，通过晋级门槛。

C4 对应测量 **C19-r2**，源码方案为 **C19-sverow2**，采用相邻两输出行共享输入行。本轮共保留五种候选和 **15 份测量记录**：14 份用于比较，另有一份最终 ZIP 独立复验。最终包已通过三轮官方套件，合计 **562.02 ms**，可从 [C4 提交包](https://github.com/Palm0palM/kunpeng-s2/blob/156cff4026360699b6ba6afb8a16ad99ca12a392/conv/result/C4/conv.zip) 直接下载。

## 五种优化策略与汇编证据

| 候选 | 单一优化假设 | 已取得的未插桩汇编证据 |
| --- | --- | --- |
| C15-pipe8 | 保持八累加器，流式完成相邻输入的 k0/k1，缩短输入生存期 | 完整汇编与 C3 逐字节相同；主双系数循环 56 条指令、16 fmul/16 fadd、9 次输入加载、7 ext，热点无向量溢出 |
| C16-pipe12 | 流式输入配十二累加器，摊薄每次 kernel 遍历开销 | 主循环 80 条、24 fmul/24 fadd、11 ext，热点无向量溢出；奇数末系数路径仍重载七个栈中地址偏移 |
| C17-pipe16 | 流式输入能否让十六累加器避开旧方案溢出 | 主循环 109 条、32 fmul/32 fadd、15 ext，仍有两次向量栈存储与两次读取，未消除溢出 |
| C18-tailpair | 仅四/二向量尾部复用相邻输入，减少尾部加载与循环控制 | 四向量循环 32 条、5 次输入加载、3 ext；二向量循环 20 条、3 次输入加载、1 ext；两个热点均无向量溢出 |
| C19-sverow2 | 两输出行各四向量，共八累加器，用错位 kernel 行索引共享同一输入行 | 中段循环 55 条、16 fmul/16 fadd、5 次输入加载、4 次 kernel 广播、3 ext 与 3 movprfx；首/末输入行各 32 条；三个热点均无向量溢出 |

上述热点和相关函数均未生成 FMA。无热点溢出不等于整个函数没有栈访问，外围地址和计数保存仍有成本；汇编改善也不能替代实际计时。各候选完整汇编、检查配置与静态观察保存在对应实验的 `sve-correctness-sep11/`。

## 数值顺序与一般尺寸

官方 benchmark、runner、输入、容差和 38 线程上限均未改变；没有 fast-math、没有 FMA、没有按官方尺寸分支。每个输出按 kernel 行、列升序进行分离的 float 乘法和加法，不拆分再合并部分和。横向双系数仍先 k0 后 k1，奇数末系数补算；最后向量使用偏移一列的有效窗口加载，不额外读取完整下一向量。VL 从当前工作线程查询，未固定为 512 位。

C19 的第一输出行依次使用 kernel 行 0..kh−1，第二输出行也独立按 0..kh−1 顺序：顶端输入只贡献第一行，中段输入分别匹配 kernel[t] 与 kernel[t−1]，底端输入只贡献第二行。kh=1 时中段为空，两个独立端部循环分别完成两行。

C19 以 `oh/2+oh%2` 计算行对数量，避免 oh+1 溢出；每个迭代独占输出行 2p、2p+1，奇数末行使用原 C3 prefix。rowpair 只在第二输出行有效时调用，最大输入行 `j+kh≤inputHeight−1`；每行最后偏移 1 加载不越过输入行尾。不足四向量的宽度余数逐行交回原 prefix。静态复核未发现行覆盖、并行写或边界遗漏。

## 超算验证范围

五种候选共完成 **110,496 项专项检查**：C15/C16/C18 各 19,752，C17 为 21,120，C19 为 30,120，全部通过。每种覆盖 1/4 线程、128/256/512 位 SVE，包含保护页、只读 input/kernel、输出毒值与 canary、严格独立标量参考逐位一致和真实 SVE helper 入口验证。计数包含独立入口 smoke，不是性能样本数。

C17 扩充了十六向量与两倍主块边界；C19 除既有奇数输出高度 3/5 外，增加高度 1/2/8，覆盖单行、完整行对和多个线程的行对分配，并涵盖 kh/kw=1、奇偶矩形 kernel 与四向量周围的宽度。C19 每配置都确认实际进入 rowpair、prefix 和 tail。

实验与发布工具的 **68 项测试也在调度计算节点全部通过**，相关工具/测试源码身份与节点收到的文件一致，见 [工具验证证据](../records/evidence/conv-sep11-toolcheck/README.md)。测试输出中的失败示例属于预期负向测试，不能误解为这次测试失败。

本轮所有编译、题目正确性与性能运行、工具测试均在超算调度计算节点进行，本机仅轻量编辑、连接、传输与日志整理。**本轮未运行 sanitizer。**
