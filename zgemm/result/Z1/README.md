# ZGEMM Z1 提交包

优先提交。直接下载本目录的 [zgemm.zip](zgemm.zip) 交给比赛平台；无需把结果记录一起压缩。

源码实验：`Z1-control2`。策略：将 A 重排为三行 K 优先连续微面板，NEON lane 读取九个分量；保持 3×4、MB24、3M 顺序。

本版本最新复测：`Z1-control2`，逐用例中位数合计 **3737.22 ms**。三组官方用例、三轮完整套件，9/9 PASS，最大绝对误差 6.04e-12，小于官方容差 1e-10。

每轮值是 benchmark 内 TEST_RUNS=3 次计时的均值；下表中位数来自三轮独立均值。该指标不是比赛分数。

| M×N×K | 第 1 轮 ms | 第 2 轮 ms | 第 3 轮 ms | 中位数 ms | 最大误差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 7427×7427×256 | 243.21 | 242.76 | 242.09 | 242.76 | 3.05e-12 |
| 14848×14848×256 | 962.34 | 963.83 | 962.70 | 962.70 | 3.51e-12 |
| 37360×8192×512 | 2530.06 | 2535.16 | 2531.76 | 2531.76 | 6.04e-12 |

晋级依据是同一作业中的 Z0-pair1 与 Z1-pack-pair1：4554.89 → 3738.92 ms，耗时下降 17.914%。最新 Z1-control2 是相同源码复测，不新增版本号。

运行环境：HiSilicon aarch64，单 NUMA，38 线程，GCC 10.3.1，`-O3 -ffp-contract=off -fopenmp -mcpu=generic`，官方内置参考实现，无外部 BLAS。顺序对照并非交错测试，不能完全排除时间漂移。

ZIP 与原提交包保持相同布局：`zgemm/zgemm.c`、`zgemm/bench_zgemm.c`、`zgemm/run.sh`、`zgemm/README.md`；`run.sh` 保留可执行位。四个文件逐字节匹配已验证的源码快照。包内 runner 默认 TEST_RUNS=1；要重现记录应在计算资源内设 TEST_RUNS=3，并独立执行三轮。此次仅重新打包，没有新运行超算。
