## 使用与反馈

下载版本目录中的 ZIP，手动提交后在该目录 README 的空白表格或 metadata.json 的 official_score、ranking、submission_date、platform_feedback 字段补充结果，反馈时带上版本号与 ZIP SHA-256。三题各自比较，不跨题比较耗时。
