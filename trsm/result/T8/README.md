# TRSM T8 提交包

下载 [trsm.zip](trsm.zip)，选择比赛 TRSM 题目后原样上传，无需重新压缩版本目录。

当前正式版本为 **T8 = T8-svepanel16**：小工作集前代采用 16 行 × 8 RHS 的 SVE 微核，让历史 X 向量被 16 行复用；保持递增求和顺序，块内使用显式 FMA，已按原 `1e-12` 容差验收。不足 16 行由原 NEON4/标量路径处理，SVE 能力和分配失败回退保留；大工作集仍用 T7。ZIP 从 main 已验证的 `outputs/trsm-best.zip` 直接复制，大小 **11,740 bytes**，未改源码或重新压缩。

同分配三轮作业 **1576028** 中，T7 与 T8 三项中位数合计 **508.56 → 447.59 ms，降低 11.99%**，超过本轮 7.67% 波动门槛。收益主要来自前两个小工作集用例；不把未改变大工作集的 0.46% 差异称为新优化，也不与历史 OpenBLAS/GCC10 成绩混算。完整样本和未晋级的 noinline 候选保留在[第五轮报告](../../../docs/trsm-stage-r5-20260912.md)。
