# TRSM T1

优先提交：当前晋级版。 提交文件为 [trsm.zip](trsm.zip)，可直接下载上传。不要上传整个 result 文件夹。

- 实现版本：`T1-panel`；确认测量：`T1-panel-r2`；推荐顺序：1。
- 优化策略：将已解 256×8 RHS 块共享打包为连续面板，供下方 4×8 更新复用；其余算法、分块、runner 和 benchmark 保持不变。
- 合计中位耗时：**758.31 ms**。这是内部比较指标，不是比赛分数。
- 三轮完整官方用例全部通过（9/9），最大绝对误差 `1.11e-15`，容差 `1e-12`。
- 包内源码逐字节对应已测快照；布局与原提交包一致，含 `trsm/` 顶层目录，`run.sh` 保留可执行权限。
