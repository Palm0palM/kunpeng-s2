# TRSM T7 提交包

下载 [trsm.zip](trsm.zip)，选择比赛 TRSM 题目后原样上传，无需重新压缩版本目录。

本包为当前已晋级 **T7 = T7-diagpanel**：大工作集的对角块直接在共享连续面板中用既有 4×8 NEON 前代求解，写回 B 并留下已解 X，合并独立打包阶段；保留 T5 的 16×8 SVE 更新、运行时分派及分配失败回退。ZIP 从 main 已发布的 outputs/trsm-best.zip 原字节复制，没有改源码或重新压缩。

同分配三轮对照（作业 1522032），T5 控制与 T7 三项中位数合计 **508.24 → 467.29 ms，降低 8.06%**；大用例 **227.13 → 191.06 ms，降低 15.88%**。改善超过 3.67% 观测波动门槛，无用例中位数退步超过 1%。小、中工作集代码未改变，不能单独把其计时差别归因于本策略。耗时是内部指标，不是官方分数。

## 已完成的包级验证

最终 ZIP 在计算节点作业 **1524188** 解压并按包内原 run.sh 运行三轮完整官方套件，**9/9 PASS**，最大误差 **1.11e-15**。环境为 GCC 10.3.1、generic、38 线程单 NUMA、close/cores 绑定，参考库为 **OpenBLAS 0.3.28 静态库**。调度器 SUCCEEDED，jobExitCode、systemExitCode 和 wrapper 退出码均为 0。

| 用例 M×N | 三轮样本 ms | 中位数 ms | 最大误差 |
| --- | --- | ---: | ---: |
| 512×19968 | 22.34 / 22.23 / 22.44 | 22.34 | 1.67e-16 |
| 2432×17024 | 257.17 / 253.26 / 254.41 | 254.41 | 2.22e-16 |
| 17024×512 | 190.45 / 190.72 / 191.29 | 190.72 | 1.11e-15 |

每个样本是 TEST_RUNS=3 的平均值，再对三个独立完整套件取中位数，合计 **467.47 ms**。此单版本复跑用于确认交付包，不替代同分配优化对照。

同一 ZIP 另经 **KML 25.1.0 + GCC 12.3.1** 独立解压复跑三轮（作业 **1528027**），**9/9 PASS**，最大误差 **1.11e-15**；实际使用 KML 动态库，无 OpenBLAS 依赖。三项中位数为 **24.36、291.20、194.30 ms**，合计 **509.86 ms**。参考库和编译器不同，此次耗时不用于与 OpenBLAS 结果计算策略提速。

**比赛指定的 KML 25.2.0 复验仍未完成。** 原流程按用户要求未执行远端哈希验证，远端源码身份与传输完整性未经哈希核验；本目录的 SHA-256 仅标识复制后的本地分发文件，不改变该历史结论。没有在本机编译或运行题目。

ZIP 保持 trsm/ 顶层目录，其中恰有 README.md、bench_trsm.c、compat/kblas.h、run.sh、trsm.c 五个文件，runner 保留执行权限；包中不含参考库二进制或账号配置。
